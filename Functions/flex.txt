Flex is a CSS layout system that helps you arrange items easily inside a container.
like:- A parent box tells its child boxes how to line up.
after display: flex;?
Items line up in a row by default
Spacing becomes easy
Centering becomes easy
Items can grow, shrink, or move neatly

Flex container → the parent
Flex items → the children inside

<div class="container">
  <div>Box 1</div>
  <div>Box 2</div>
  <div>Box 3</div>
</div>

Common Flex Properties

Row or Column:

flex-direction: row;    left to right (default) 
flex-direction: column;  top to bottom 

Center items:

justify-content: center; horizontal 
align-items: center;      vertical 

Space between items

justify-content: space-between;

Why use Flex?
Easy alignment
Easy centering
Responsive layouts
Less CSS, more control

Flex makes arranging and aligning items inside a container simple and powerful.
